# HouseGuide — VST3-плагин для FL Studio 24

Помощник для house / deep house / organic house / nu disco / afro house.
Плагин НЕ меняет звук, пока вы сами не крутите панораму, ширину или ВЧ-фильтр.

## Что умеет
1. **Тональность** (A minor, Camelot 8A) — определяется по звуку, который идёт через канал.
2. **Темп** — берётся из FL Studio (точно) + оценка «на слух» для сверки.
3. **Клиппинг** — красный индикатор на канале, где сигнал дошёл до 0 dB. В «мини-микшере» видны ВСЕ копии плагина сразу: какой канал клиппует, подсвечен красным.
4. **Подсказки по частотам** — график «красное = лишнее, синее = не хватает» и 3–4 конкретные фразы («Срежьте ~3 дБ около 250 Гц»). Для разных жанров и разных источников (кик, бас, вокал, хэты…) свои правила.
5. **Настройка звука и панорама** — рекомендации для каждого типа звука + ручки «Панорама / Ширина / ВЧ-фильтр» и кнопка «Применить рекомендации». Предупреждает о проблемах с фазой.
6. **Инструменты: пианино, гитара, флейта, виолончель** (плюс бас и лид) — для каждого генерируется своя партия под тональность и жанр:
   - пианино — аккорды (7-е и 9-е для deep / organic / nu disco);
   - гитара — арпеджио или «чопы» по аккорду;
   - флейта — редкие длинные фразы в верхнем регистре, с паузами;
   - виолончель — тянущиеся ноты, опора гармонии.
   Каждый инструмент включается и выключается галочкой. В MIDI-файле у каждого своя дорожка и свой звук General MIDI.
7. **Прослушка внутри плагина** — галочка «Слушать партии в плагине» + Play в FL: инструменты играют встроенным синтезатором синхронно с проектом (цикл 4 такта от начала проекта, размер 4/4). Это синтез, а не сэмплы: звук упрощённый, для набросков. Для финального звука перетащите MIDI на ваши любимые VST.
8. **Сайдчейн** — придавливание звука под кик (эффект «дыхания» в house). Включается галочкой на канале. Есть два режима:
   - **Внутренний (по темпу проекта)** — работает сразу, ничего подключать не нужно: плагин сам «нажимает» на каждую долю (1/4), на 1 и 3 доли (1/2) или на восьмые (1/8) в такт темпу FL. Нужен Play. Это основной режим.
   - **Внешний (вход Sidechain)** — как обычный компрессор: придавливает, когда на вход Sidechain приходит громкий кик. Нужна маршрутизация в FL (см. ниже).
   Ручки: глубина, атака, возврат, форма возврата, порог (только для внешнего режима). На графике видно форму придавливания, рядом показано, на сколько дБ звук придавлен сейчас.
   Для каждого типа звука есть рекомендации: бас (глубоко, коротко), пэды и аккорды, пианино, гитара, флейта, виолончель, лид, FX (средне), вокал (лишь чуть-чуть). Кнопка «Применить рекомендации» подставляет их, учитывая жанр и темп проекта. Кик, клэп, хэты и перкуссию сайдчейн не трогает.
9. **Генератор партий под вокал** — загрузите/перетащите файл вокала (или включите «Авто» на канале с вокалом). Плагин определяет тональность и генерирует 4 такта: аккорды, бас, мелодию под выбранный жанр. Внизу показывается пиано-ролл. Готовый MIDI-файл перетащите в FL Studio.

## Как собрать (вариант А — без установки программ: через GitHub)
1. Зарегистрируйтесь на github.com → New repository → загрузите ВСЮ папку проекта (включая скрытую `.github`).
2. Вкладка **Actions** → **Build HouseGuide VST3** → **Run workflow**.
3. Через 5–10 минут откройте завершённый запуск → внизу **Artifacts** → скачайте `HouseGuide-VST3`.

## Как собрать (вариант Б — на своём компьютере, Windows)
1. Установите: Visual Studio 2022 Community (галочка «Разработка классических приложений на C++»), CMake, Git.
2. В «Developer Command Prompt for VS 2022»:
```
cd C:\HouseGuide
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```
3. Готовый плагин: `build\HouseGuide_artefacts\Release\VST3\HouseGuide.vst3`

## Установка в FL Studio 24
1. Скопируйте папку `HouseGuide.vst3` в `C:\Program Files\Common Files\VST3\`
2. FL Studio → **Options → Manage plugins → Find installed plugins**
3. В Mixer на нужном канале: пустой слот эффектов → **HouseGuide**.
   - на каждом канале (кик, бас, вокал…) выберите «Что за звук» и своё имя канала;
   - на мастере выберите «Мастер / весь микс».
4. Для вокала: слот эффектов на канале вокала → Play → через несколько секунд плагин покажет тональность → «Сгенерировать партии».


## Новые модули обработки (страницы-вкладки в окне плагина)
Вкладки: **Анализ**, **Сайдчейн и партии**, **Динамика и EQ**, **Мультиполоса и тембр**, **Стерео и эффекты**, **Ассистент (ИИ)**. Каждый модуль включается отдельно и по умолчанию выключен, поэтому звук не меняется, пока вы сами не включите нужное.

1. **Динамический EQ** (3 полосы) — срабатывает только когда в полосе появляется лишний сигнал выше порога. Диапазон «−» срезает, «+» подчёркивает. Видно, сколько дБ сейчас убирается.
2. **Креативный EQ (carve and boost)** — «вырез» (освободить место, обычно 2–4 кГц) и «подъём» (подчеркнуть главное, например 4–6 кГц вокала). Вырез может срабатывать только когда на канале с ролью «Вокал (лид)» есть голос (каналы в одном проекте FL «видят» друг друга).
3. **Мультиполосный компрессор** для групп (низ / середина / верх): порог, степень, атака, возврат, усиление на каждую полосу, микс (параллельная компрессия) и страховочный лимитер на выходе.
4. **Тембр и гармоники** — насыщение (лента, лампа, фолд, эксайтер «воздух») и творческий фильтр, чей срез движется в такт проекту.
5. **Стерео и эффекты** — «моно ниже частоты», дилей (пинг-понг в темп проекта) и реверб, у каждого свои уровень, ширина, панорама и срез НЧ.
6. **Ассистент (ИИ)** — «Авто-настройка по анализу звука» (сама включает и настраивает модули по найденным перекосам, роли и жанру), 8 готовых стилей обработки, кнопка «Сбросить всё» и переключатель A/B «обойти всю обработку».

Важно про «ИИ»: ассистент — это правила и измерения, а не нейросеть. LANDR, eMastered и Moises — внешние облачные сервисы, встроить их в плагин нельзя. Практичный порядок: разделить трек в Moises на стемы, разложить по каналам FL, на каждом поставить HouseGuide и нажать «Авто-настройка».

## Сайдчейн: как пользоваться
Внутренний режим (проще всего):
1. Поставьте плагин на канал баса (или пэда, пианино и т. д.).
2. В списке «что за звук» выберите нужный тип и нажмите «Применить рекомендации».
3. Нажмите Play: график покажет кривую, а счётчик внизу покажет придавливание.

Внешний режим (по сигналу кика): в Mixer выберите канал кика → правой кнопкой по стрелке отправки на канал баса → «Sidechain to this track». Затем в окне плагина на канале баса откройте шестерёнку и в настройках входов выберите вход Sidechain (расположение зависит от версии FL). В плагине выберите источник «Внешний». Если не получилось, используйте внутренний режим.

## Прослушка: если звука нет
- Плагин должен стоять на канале Mixer, и в проекте должен идти Play.
- В FL Studio нажмите на шестерёнку в окне плагина и отключите «Smart disable» (если включено): иначе FL может «усыплять» эффект без входящего звука.
- Лучше ставить плагин на канал вокала или на любой канал со звуком.
- Партия сохраняется вместе с проектом FL.

## Ограничения (честно)
- VST3-эффект не может сам играть звуки или вписывать ноты в Piano roll FL — поэтому партии выдаются MIDI-файлом (перетаскиваете в Channel rack / Playlist). Если перетаскивание не сработает, клик по плашке MIDI откроет папку `Документы\HouseGuide`.
- Новые модули написаны без компиляции и проверки на слух. Возможна нужда в подстройке; пороги и стартовые значения — ориентиры.
- Бас и лид в плагине не звучат, они только в MIDI (играйте их своими синтезаторами).
- Определение тональности и темпа — оценка. На басовых/ударных лупах без гармонии ошибается. Всегда проверяйте ухом.
- Целевые кривые частот (`Source/Advisor.h`, функция `targetCurve`) — моя эвристика, а не измеренные «тренды 2026». Подстройте цифры под ваши любимые референсные треки.
- «Мини-микшер» видит только копии плагина, загруженные в одном процессе FL (по умолчанию так и есть, если плагин не в режиме bridge).
- Код написан без компиляции и тестов на вашем железе: возможны мелкие ошибки сборки — пришлите текст ошибки, исправлю.
- Лицензия JUCE: для личного использования бесплатно, для продажи/раздачи плагина нужна лицензия JUCE.
